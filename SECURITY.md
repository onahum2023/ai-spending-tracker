# Security policy

AI Spending Tracker runs in the browser and has no backend, so there is no server-side data to breach. Reports are still welcome, especially about anything that could make financial data leave the browser (for example a Content-Security-Policy bypass, an injection in imported files, or mishandling of the optional Anthropic API key).

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private reporting: **Security → Report a vulnerability** on this repository. If that is not available to you, email info@neotixhq.com.

Include what you found, how to reproduce it, and the version (shown in the app under **Data → About**). We will acknowledge the report and keep you updated until it is resolved.

## Supported versions

Only the latest release and the `main` branch are supported.
